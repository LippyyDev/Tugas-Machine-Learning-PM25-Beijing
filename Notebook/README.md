# Notebook

| Berkas | Isi |
|---|---|
| `Tahap 2 EDA dan Praproses.ipynb` | Muat data, EDA, pembagian kronologis, skema validasi, dan fitur untuk Tiantan |

Cara menjalankan ada di `README.md` utama. *Notebook* mencari data di folder Google Drive, lalu `Data/Data Mentah` (dari akar repo atau dari folder ini), dan bila keduanya tidak ada mengunduh repo ini.

Keluarannya ditulis ke struktur yang sama dengan repo: grafik ke `Hasil/Gambar`, tabel ke `Hasil/Tabel`, fitur ke `Data/Data Olahan`. Di Google Drive, ketiga folder itu dibuat di bawah folder `Dataset PM25 Beijing`. Nama grafik dan tabel diawali `t2_` (tahap 2).
