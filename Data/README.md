# Data

Semua data proyek. Isinya dipisah menurut tahap pengolahan.

| Subfolder | Isi |
|---|---|
| `Data Mentah` | 12 CSV asli per stasiun dari UCI. Tidak diubah |
| `Data Olahan` | Tabel fitur Tiantan (latih dan uji) hasil *notebook* tahap 2 |

Alurnya: `Data Mentah` → *notebook* tahap 2 → `Data Olahan`. Data olahan bisa dibuat ulang dari data mentah, sedangkan data mentah tidak boleh ditimpa.
